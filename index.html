Welcome to the World of the Web

The Internet and the World Wide Web have changed the way people communicate, learn, work and share information.

This assignment introduces the basic concepts of Internet and Web Fundamentals.

Image represents modern Internet and networking technology.

1. The Internet

The Internet is a global network of interconnected computer networks that communicate using standard protocols such as TCP/IP.

Important Points

  • ARPANET (1969) was one of the earliest operational packet-switching networks.
  • The Internet connects computers, servers, smartphones and other devices worldwide.
  • It allows people to communicate and share information across the world.
Did You Know?

The Internet is the infrastructure, while the Web is one of the services that operates over the Internet.

2. The World Wide Web (Web)

The World Wide Web (WWW) is a collection of digital or electronic resources available via the Internet.

The Web allows users to access interconnected web pages through hyperlinks.

  1. Invented by Tim Berners-Lee in 1989.
  2. Uses HTML to structure web pages.
  3. Uses HTTP/HTTPS for communication.
  4. Uses URLs to locate resources.
  5. Web browsers display web pages.

3. W3C — World Wide Web Consortium

The W3C develops and maintains standards and recommendations for the Web.

Examples include:

  • HTML
  • CSS
  • Web Accessibility
  • Web Architecture

Visit the official W3C Website for more information.

4. Web Page

A web page is a single document available on the Web, usually created using HTML.

Example: https://example.com/about.html

The About page is an example of one web page.

5. Website

A website is a collection of related web pages and resources available under a common domain.

Example: www.example.com

A website may contain:

  • Home Page
  • About Page
  • Contact Page
  • Services Page
  • Blog Pages

6. Home Page

The home page is generally the main or introductory page of a website.

It normally provides navigation to other important sections of the website.

Visit Example Home Page

7. Index Page

An index page is commonly the default page served when a website location is accessed.

Typical filenames:

  • index.html
  • index.php
  • index.htm

Home page and index page are related concepts, but they are not necessarily identical.

8. Landing Page

A landing page is a web page designed for a specific purpose, often after a user clicks an advertisement, email link or search result.

Typical goals:

  1. Register for a course
  2. Buy a product
  3. Download an application
  4. Submit a form

9. Web Browser

A web browser is software used to access and display web pages.

Examples:

  • Google Chrome
  • Mozilla Firefox
  • Microsoft Edge
  • Safari
Basic Function:

Browser → Request → Web Server
Web Server → Response → Browser

10. Web Server

A web server is a computer/system and software that stores, processes and delivers web resources to clients.

Common Web Server Software

  • Apache
  • Nginx
  • Microsoft IIS

11. Web Domain

A domain name is a human-readable name used to identify a website or Internet service.

Example: www.example.com

Instead of remembering an IP address such as 93.184.216.34, users can use a domain name.

12. URL — Uniform Resource Locator

A URL specifies the location of a resource and how to access it.

Example URL

https://www.example.com/about.html

https:// = Protocol
www.example.com = Domain
/about.html = Resource/Page

13. URI — Uniform Resource Identifier

A URI is a broader concept used to identify a resource.

A URL is a type of URI.

Term Meaning
URI Identifies a resource.
URL Identifies a resource and provides its location/access method.

14. HTTP — HyperText Transfer Protocol

HTTP is the protocol used for communication between web clients and servers.

HTTP commonly uses port 80. 


```

Browser → HTTP Request → Server
Browser ← HTTP Response ← Server
```

15. HTTPS — HyperText Transfer Protocol Secure

HTTPS is HTTP communication protected using modern cryptographic security, primarily through TLS.

HTTPS provides:

  • Encryption
  • Authentication
  • Data Integrity

HTTPS commonly uses port 443.

16. SSL — Secure Sockets Layer

SSL was an earlier security protocol designed to secure network communication.

Important: SSL has been deprecated and replaced by TLS.

17. TLS — Transport Layer Security

TLS is the modern cryptographic protocol used to secure communications such as HTTPS.

Simple TLS Model:

Browser → Secure TLS Connection → Web Server

19. IP Address

An IP address is a unique numeric address that identifies a device on the Internet or a local network.

Examples

  • IPv4: 192.168.1.10
  • IPv6: 2001:db8::1

A domain name can be translated into an IP address so that network communication can take place.

20. DNS — Domain Name System

DNS translates human-readable domain names into IP addresses and performs other naming functions.

Example:

www.example.com → DNS → 93.184.216.34

21. NSlookup / nslookup

nslookup is a command-line tool used to query DNS information.

Example Command

nslookup example.com

It can help determine:

  • IP addresses associated with domains
  • DNS server information
  • DNS records

22. Search Engines

A search engine is a service that helps users find information and web pages on the Internet.

Examples

  • Google
  • Bing
  • DuckDuckGo

Basic Process

User enters query → Search Engine → Search Index → Relevant Results → User selects a result

23. ChatGPT

ChatGPT is an AI-based conversational system developed by OpenAI.

It can understand natural-language prompts and generate responses, explanations, summaries, code and other content.

Search Engine vs ChatGPT

Search Engine ChatGPT
Primarily helps users find existing information. Primarily generates responses based on its model and available information/tools.

Final Summary

The Internet provides the global networking infrastructure, while the World Wide Web provides interconnected web resources accessed through browsers.

Technologies such as HTML, URLs, HTTP, HTTPS, DNS and IP addresses work together to make the modern Web possible.
